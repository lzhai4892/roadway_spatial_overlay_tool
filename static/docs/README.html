Roadway Line-to-Line Overlay Tool v1.0

Spatial GIS line-to-line overlay for transportation planning. Geometry only — no linear referencing locate.

1. Mathematical Methodology

This tool evaluates spatial alignment between a Destination (Target) Layer and a Reference Layer. It does not use roadway IDs, mileposts, or Work Program / RCI linear-referencing locate fields to find matches:

  • Corridor Buffer: Default 300 ft buffer around reference centerlines.
  • Minimum Overlap: Overlap length ≥ 300 ft and overlap ratio ≥ 10% of target length (default Min Target Ratio).
  • Undirected Local Bearing: Bearings are evaluated over a 500 ft window centered on the overlap midpoint. Direction is evaluated modulo 180° / 90° to handle opposing digitizing directions.
  • Parallel Fallback: Optional second rule. User sets min destination coverage (default 75%) and max distance (default 30 ft) for short dests that fail the primary min-overlap test.

2. Supported Input Formats

  • Zipped Shapefiles (.zip) containing .shp, .dbf, .shx, and .prj.
  • GeoJSON (.geojson / .json)
  • KML (.kml)
  • GeoPackage (.gpkg)
  • CSV (.csv) with WKT geometry or coordinates.

3. Attribute Transfer & Expressions

You can choose single reference columns or compose templates such as {ITEMSEG} - {high_yr_ph} or {WPITEM}-{WPITMSEG}. Those values are labels only; matching stays spatial.
