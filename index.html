How this tool works v1.0

What this tool is for

Use it when you have two line layers and need to know which destination segments sit on the same corridor as a reference network — then stamp a label from the reference onto the destination.

  • Typical jobs: safety treatments vs Work Program items, bottlenecks vs SIS or RCI linework, candidate approaches vs a project layer. Reference can be any line network, not only Work Program.
  • Matching is geometry only: buffer, overlap length, and local heading. It does not join on ROADWAY, BMP/EMP, BEGIN_MILE / END_MILE, or Work Program / RCI locate status. Those LRS fields can be wrong; overlay uses the drawn linework.
  • After a spatial hit, destination receives match status, overlap, angle, QC, and a Matched ID you compose from reference attributes (Output labels). Those fields are labels, not a locate join.

How a run works

  • 1. Input layers. Load destination and reference. Line files: shapefile (.zip or .shp+.dbf), GeoJSON, KML/KMZ, or CSV. After destination loads, pick the Destination ID field to show in the table (demo data often has LocationID; other files may use OBJECTID or another attribute). That choice is a label only.
  • 2. Match rules. Set buffer, min overlap, min target ratio, max angle, bearing window, and optional Parallel Fallback. Defaults stay unless you change them. Load sample demo sets min overlap to 75 ft and Unique Matched IDs for that example.
  • 3. Output labels. Pick reference fields (or an expression such as {WPITEM}-{WPITMSEG}) to build Matched ID after a spatial hit. If several references match one destination, keep every ID in the cell or unique IDs only. Count still lists every hit.
  • Run computes overlay in this browser. The map draws reference behind destination (green matched, orange unmatched, slate dashed reference). The table sorts matched first, then angle mismatch, then unmatched. Export names use destination_x_reference.

Parameter Breakdown & Engineering Rationale

1. Buffer Distance (ft)
What it is: The lateral search corridor (width ±Buffer) generated around the destination centerline.
Why it is needed: Two GIS line layers rarely share identical coordinates. Divided roads, medians, and digitizing offset are handled by a search width around the destination line. This tool does not snap to RCI / Work Program mileposts or use the linear referencing locate system.
2. Min Overlap Length (ft)
What it is: The minimum shared longitudinal length that the reference line must run along the destination corridor.
Why it is needed: Perpendicular cross-streets, overpasses, and turning ramps will briefly intersect the buffer corridor for 50–100 ft. Requiring a substantial minimum overlap (e.g. 300 ft) discards accidental intersection touches.
3. Min Target Ratio (%)
What it is: The minimum proportion of the destination feature's total length that must be covered (L_overlap / L_destination × 100).
Why it is needed: Ensures proportional match significance. A 300 ft overlap on a 5-mile (26,400 ft) segment is only 1.1% (a minor clip), whereas 300 ft on a 400 ft bottleneck is 75% (a major corridor match).
4. Max Angle Delta (°) — local window, same value as the results table
What it is: The maximum heading difference measured on a short window (default 500 ft) centered on the overlap, not the first-to-last vertex of the whole feature. A long or curving destination or reference line does not change the angle at this overlap.
Why it is needed: Cross-streets are ~90° at the overlap and are rejected. The Angle Diff column is this same local value for the best match, so the filter and the table agree.
Modes: Ignore line direction (default) folds reverse digitizing to 0°–90°. Check vertex direction keeps travel sense; opposite vertices report ~180°.
5. Parallel Fallback (user-set coverage and distance)
What it is: A second rule for short destination lines that fail the primary min-overlap test. You set Min Coverage (%) and Max Distance (ft). Primary matches still use Max Angle. Fallback heading may be looser: it allows up to the larger of Max Angle and 45° (so 45° when Max Angle is 30°).
Why it is needed: Intersection approaches and short turn sticks are often under 75 ft long. If most of that stick sits on the corridor and stays close, it is the same roadway even when min overlap is not met. Defaults are 75% and 30 ft; raise coverage or tighten distance if too many crossings qualify.

Parameter Default Recommended Range When to Adjust
Buffer (ft) 300 ft 100 – 500 ft Increase for wide Interstate medians (e.g. 500 ft) or decrease for dense downtown grids (e.g. 100 ft).
Min Overlap (ft) 300 ft 100 – 1,000 ft Increase to ignore short turn-lane connectors or ramps; decrease for short intersection bottlenecks.
Min Target Ratio (%) 10% 10% – 30% 10% lets a short reference item match a long destination. Raise it if too many glancing clips qualify.
Max Angle Delta (°) 30° 15° – 45° Keep at 30° for general highways. Increase to 45° for curved cloverleaf interchange ramps.
Bearing Window (ft) 500 ft 200 – 1,000 ft Heading uses this local stretch at the overlap, not the whole line. Increase on gentle interstate curves; decrease in dense grids so a nearby turn is not mixed into the heading.
Fallback Min Coverage (%) 75% 50% – 90% Lower for very short dests that only clip the corridor. Raise if crossing streets start matching.
Fallback Max Distance (ft) 30 ft 15 – 50 ft Widen for divided dual carriageways. Tighten in dense grids so a nearby parallel street does not qualify.
Working CRS WGS84 Always EPSG:4326 after load Source CRS fallback is used only when a projected file has no .prj. Distances and angles are geodesic in WGS84.

Map, table, and export

  • Map. Destination draws in front (green matched, orange unmatched). Reference is a dashed slate line behind. Basemap → None hides street/aerial tiles. Extent zooms to loaded layers. The compass (top right) returns the map to north. A scale bar sits at the lower left. Measure draws a geodesic path in feet (and miles when long); Escape or Clear exits. Layer styles control color, width, opacity, and pattern. Segment details open in the lower-right card, not on the line, so overlap stays visible after a table click.
  • Table. Destination ID comes from the field you pick after load. Matched ID(s) lists reference labels; more than five IDs show the first five and See all. Default sort is Matched → Angle mismatch → Unmatched. Click a row to zoom the map and fill the corner card.
  • Export. Shapefile, Excel, GeoJSON, or CSV. The download name is {destination}_x_{reference}. The file still contains every Matched ID, not the truncated table view. Shapefile zip includes a *_MatchRules.txt sidecar by default (Match rules checkbox); uncheck to omit it. Extra files in the zip do not change the .shp/.dbf.
